# Kidney model

The kidney, cortex, columns of Bertin, pyramids, papillae, pelvis, calyces, ureter, renal artery and renal vein are meshes from the Human Reference Atlas organ set already used on this site.

Kristen Browne and Heidi Schlehlein, 3D Reference Organ Set for United, Male, v1.5 (2023), HuBMAP. Created using Visible Human Male data from the US National Library of Medicine.

- DOI: https://doi.org/10.48539/HBM646.RKKC.257
- Library: https://humanatlas.io/3d-reference-library
- License: Creative Commons Attribution 4.0 International

Only the left kidney and its vessels and ureter were kept. Transforms were baked, the group was centred, and display colours were applied in the viewer. The cut is a clipping plane through those source meshes. It is a teaching cross-section, not a new scan.

The single-nephron model, the blood and filtrate particles, and the filtration numbers are a custom teaching model. They are not part of the atlas mesh.

Z-Anatomy and BodyParts3D are the source of the heart model elsewhere on this site. This kidney uses the Human Reference Atlas because that atlas separates cortex, medulla and pelvis.
