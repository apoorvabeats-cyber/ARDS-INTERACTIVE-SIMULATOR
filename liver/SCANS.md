# Radiology images in the liver learning lab

These are real studies from Wikimedia Commons, copied here so the lab still opens if the network image host is slow. They are not drawings. This file is the licence record. It is not shown in the app.

Each disease page names the modality and what that film actually shows. Where a disease has no single diagnostic picture, the caption says so. The mark on the film is added in the lab. It is not part of the source image.
