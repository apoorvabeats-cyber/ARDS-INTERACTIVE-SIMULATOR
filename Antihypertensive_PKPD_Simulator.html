UNDER THE HOOD

Model structure

⌄
PK layer. A one-compartment disposition model with an effect-site (biophase) link. Infusions are modelled as a constant input rate R with Css = R / CL; boluses as an instantaneous central-compartment input; oral doses via a first-order absorption compartment (ka, bioavailability F). Apparent clearance is adjusted for renal and hepatic function using drug-specific fractional contributions. Integration uses small fixed time steps with exact exponential updates, so results are stable at any selected duration.

PD layer. Effect-site concentration drives a sigmoid Emax / Hill relationship E = Ch / (EC50h + EC50h). Separate Emax terms for SBP and DBP produce the pressure curve; MAP is then computed as (SBP + 2·DBP) / 3. Heart rate = baseline + direct drug effect + baroreflex gain × MAP fall.

Limitations. No inter-individual variability, no active metabolites, no reflex-adaptation or tolerance, no ICP/CO/PA-pressure modelling, and no interaction with sedatives or vasopressors. Parameter values are teaching approximations and must not be interpreted as patient-specific kinetics.
